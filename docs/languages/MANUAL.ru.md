<h2><img src="https://api.iconify.design/solar/box-bold.svg?color=%233B82F6&width=26" align="top" /> &nbsp;Как устроен сервер</h2>

Обычная игра обращается к серверам разработчика за всем, кроме самой стрельбы: вход, профиль, инвентарь, комнаты, кланы, магазин. EmuWarface встаёт на их место на вашей машине.

В работе участвуют четыре части:

| Часть | Роль |
|---|---|
| **EmuWarface** | Отвечает клиенту: вход, профиль, комнаты, предметы |
| **MySQL** | Хранит аккаунты, профили, инвентарь, кланы |
| **GameData** | Конфигурационные файлы игры (миссии, предметы, награды) |
| **Клиент игры** | Сам Warface, направленный на ваш сервер |

Общение идёт по **XMPP**, порт **5222**.

> [!IMPORTANT]
> EmuWarface **не** проводит сам матч. Он отвечает за лобби, профили и комнаты. Бой запускает `DedicatedServer.exe`, который идёт с клиентом игры.

> [!WARNING]
> В исходном коде **нет папки `GameData`**, а без неё сервер не запустится. Она входит только в релизы. Если вы клонировали репозиторий, скачайте [релиз](https://github.com/OTheMandaloriano/EmuWarface/releases) и скопируйте `GameData` оттуда рядом с исполняемым файлом.

### По шагам

**1. База данных.** Создайте её и импортируйте схему:

```bash
mysql -u root -p -e "CREATE DATABASE emuwarface CHARACTER SET utf8mb4"
mysql -u root -p emuwarface < EmuWarface/emuwarface.sql
```

Это создаст 26 таблиц и добавит тестовые аккаунты.

**2. Подключение к базе.** В `Config/sql.json`:

```json
{
    "server": "127.0.0.1",
    "user": "root",
    "password": "ваш_пароль",
    "database": "emuwarface",
    "characterSet": "utf8mb4",
    "port": 3306
}
```

**3. Сервер.** В `Config/settings.json` проверьте `host` и `port`. Для локальной работы подойдут `127.0.0.1` и `5222`.

**4. Запустите:**

```bash
EmuWarface.exe
```

Или из исходников:

```bash
dotnet run --project EmuWarface
```

**5. Направьте клиент** на свой сервер в файле `online.cfg`:

```
online_host = warface
online_server = 127.0.0.1
```

### Создание аккаунта

**Регистрации через игру нет.** Аккаунты добавляются прямо в базу:

```sql
INSERT INTO emu_users (login, password, token, permission, ipaddress)
VALUES ('новыйигрок', 'пароль123', '1', 0, '');
```

### Четыре уровня

| Уровень | Значение | Что доступно |
|---|---|---|
| `None` | 0 | Играть. Команды `give`, `help`, `online` |
| `Give` | 1 | Зарезервирован под выдачу предметов |
| `Moderator` | 2 | Бан, кик, мут, список комнат |
| `Admin` | 3 | Всё |

```sql
UPDATE emu_users SET permission = 2 WHERE login = 'новыйигрок';
```

<h2><img src="https://api.iconify.design/solar/command-bold.svg?color=%2322C55E&width=26" align="top" /> &nbsp;Команды администратора</h2>

Одиннадцать команд, доступных двумя способами: набором **в консоли сервера** (всегда с правами Admin) или **из игры**, с учётом прав аккаунта.

| Команда | Сокращение | Права | Назначение |
|---|---|---|---|
| `give` | `g` | None | Выдать предметы, валюту, достижения |
| `help` | | None | Список доступных команд |
| `online` | | None | Сколько игроков подключено |
| `ban` | | Moderator | Забанить аккаунт |
| `unban` | `ub` | Moderator | Снять бан |
| `kick` | `k` | Moderator | Отключить игрока |
| `mute` | `m` | Moderator | Заглушить в чате |
| `unmute` | `um` | Moderator | Вернуть голос |
| `broadcast` | `bc` | Moderator | Объявление всему серверу |
| `rooms` | `r` | Moderator | Список открытых комнат |
| `setexp` | `exp` | Moderator | Задать опыт игроку |

### Команда `give` подробно

Самая насыщенная, принимает несколько типов:

```bash
give user1 p ar29_shop            # оружие навсегда
give user1 e ar29_shop 10d        # на 10 дней
give user1 s sniper_fbs_01        # скин
give user1 b random_box_10        # случайный ящик
give user1 m game 10000           # 10 000 WF$
give user1 m crown 10000          # 10 000 корон
give user1 m cry 10000            # 10 000 кредитов
give user1 a 2231                 # достижение
```

| Тип | Сокращение | Что выдаёт |
|---|---|---|
| `permanent` | `p` | Предмет навсегда |
| `expiration` | `e` | Предмет на срок (`10d`, `3h`) |
| `skin` | `s` | Скин оружия |
| `box` | `b` | Случайный ящик |
| `money` | `m` | Валюта: `game`, `crown` или `cry` |
| `achiev` | `a` | Достижение по номеру |

> [!NOTE]
> `give user1 all` выдаёт весь каталог, но работает только при выключенном `use_online_protect`.

### Бан и мут

Обе команды принимают срок. Без срока — навсегда:

```bash
ban user1 7d          # семь дней
mute user1 2h         # два часа
kick user1
```

<h2><img src="https://api.iconify.design/solar/settings-bold.svg?color=%233B82F6&width=26" align="top" /> &nbsp;Настройка</h2>

Пять файлов в `Config/`. Все требуют перезапуска сервера.

### `settings.json` — основной

| Поле | Назначение |
|---|---|
| `host` | Адрес, который слушает сервер. `127.0.0.1` принимает только эту машину |
| `port` | Порт XMPP. По умолчанию `5222` |
| `dedicatedHosts` | Адреса, которым разрешено регистрировать выделенные серверы |
| `gameVersion` | Принимаемая версия клиента. Должна совпадать с игрой |
| `certSecret` | Пароль TLS-сертификата |
| `xmpp_debug` | Записывает трафик. Полезно для диагностики, тяжело в работе |
| `xmpp_debug_console` | Дублирует трафик в консоль |
| `use_online_protect` | Защита счётчика игроков онлайн |
| `sponsors` | Прогресс у поставщиков (см. [VENDORS.ru.md](VENDORS.ru.md)) |

### `sql.json` — база данных

Адрес, пользователь, пароль, имя базы и порт.

### `room.json` — когда начинается матч

```json
{
    "min_players_ready_pvp_public": 1,
    "min_players_ready_pvp_autostart": 2,
    "min_players_ready_pve_private": 1,
    "min_players_ready_pve_autostart": 1,
    "min_players_ready_pvp_clanwar": 1,
    "min_players_ready_pvp_rating": 4
}
```

Сколько игроков должны быть готовы, по типам комнат. На маленьком сервере значение `1` везде избавляет от ожидания.

### `masterservers.json` — каналы

В комплекте четыре канала: `pve_001`, `pvp_newbie_001`, `pvp_skilled_001` и `pvp_pro_001`. Поля `min_rank` и `max_rank` определяют, кому виден каждый.

### `defaultItems.json` — стартовый набор

72 предмета, которые получает каждый игрок при создании аккаунта:

```json
{ "name": "pt05_shop", "type": "Pistol", "classes": 29 }
```

`classes` — сумма битов: Штурмовик 1, Медик 2, Инженер 4, Снайпер 8, Тяжёлый 16. Значение `29` — это 1+4+8+16, все классы кроме Медика. Для всех ставьте `31`.

<h2><img src="https://api.iconify.design/solar/danger-triangle-bold.svg?color=%23F97316&width=26" align="top" /> &nbsp;Что не работает</h2>

Честный перечень, составленный чтением кода. В нём **119 пометок о незавершённом**, оставленных авторами.

| Ограничение | Состояние |
|---|---|
| **`GameData` нет в исходниках** | Только в релизах. Без неё сервер не стартует |
| **Нет регистрации через игру** | Аккаунты добавляются через SQL |
| **RCON** | Поле `rconPort` в коде есть, но удалённое администрирование не реализовано |
| **Награда за повышение звания** | Помечена как незавершённая в `Profile.cs` |
| **Бан по рейтингу** | Помечен как незавершённый |

> [!NOTE]
> 119 пометок не означают, что сервер нестабилен. Большинство из них — доработки и заметки авторов. Основное, от входа до матча, работает.

<h2><img src="https://api.iconify.design/solar/shield-warning-bold.svg?color=%23F97316&width=26" align="top" /> &nbsp;Безопасность</h2>

> [!CAUTION]
> **Пароли в открытом виде.** Таблица `emu_users` хранит пароли без какой-либо защиты. Любой, у кого есть доступ к базе, прочитает их все. Никогда не используйте здесь пароль, который применяете где-то ещё.

> [!WARNING]
> **Тестовые аккаунты общеизвестны.** `user1` — `user4`, пароль `12345`, все с правами Admin. Смените их до того, как откроете сервер другим.

> [!CAUTION]
> **В `sql.json` лежит пароль от базы.** Никогда не публикуйте этот файл заполненным и не передавайте вместе с проектом.

При выходе в интернет используйте файрвол и открывайте только нужный порт. Домашнему серверу место на `127.0.0.1` или за VPN.

<h2><img src="https://api.iconify.design/solar/bug-bold.svg?color=%23F97316&width=26" align="top" /> &nbsp;Если что-то пошло не так</h2>

<details>
<summary><b>Сервер закрывается сразу после запуска</b></summary>

<br>

Почти всегда одно из трёх:

1. **Нет папки `GameData`.** Проверьте, что она лежит рядом с исполняемым файлом.
2. **MySQL не запущен или пароль неверный.** Проверьте подключение из `sql.json` вручную.
3. **Пустая база.** Импортируйте `emuwarface.sql`.

</details>

<details>
<summary><b>Игра не подключается</b></summary>

<br>

- Указан ли в `online.cfg` клиента правильный адрес?
- Совпадает ли `gameVersion` из `settings.json` со сборкой игры?
- Открыт ли порт 5222 в файрволе?
- Включите `xmpp_debug` и посмотрите, что приходит в консоль.

</details>

<details>
<summary><b>Захожу в лобби, но матч не начинается</b></summary>

<br>

EmuWarface не проводит матчи — это делает `DedicatedServer.exe` из клиента. Проверьте, запущен ли он и указан ли его адрес в `dedicatedHosts`.

</details>

<details>
<summary><b>Забыл пароль от аккаунта</b></summary>

<br>

Они лежат в базе открытым текстом:

```sql
SELECT login, password FROM emu_users;
UPDATE emu_users SET password = 'новый' WHERE login = 'user1';
```

</details>
